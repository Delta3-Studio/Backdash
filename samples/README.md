# Backdash Samples

Example projects of multiplayer games using Backdash.
- **[ConsoleGame](ConsoleGame/)**: A small simple console game.
- **[SpaceWar](SpaceWar/)**: A 2D multiplayer ship battle game. See its README for run instructions and controls.
- **[SpaceWar.Lobby](SpaceWar.Lobby/)**: A version of **SpaceWar** with an online lobby and P2P connections using UDP hole punching. It uses the **LobbyServer** for peer discovery.
- **[SpaceWar.Shared](SpaceWar.Shared/)**: Shared game logic and assets used by both **SpaceWar** applications (_It is not a standalone executable_).
- **[LobbyServer](LobbyServer/)**: An HTTP/UDP server sample for managing lobbies and helping **SpaceWar.Lobby** peers discover each other.

> [!TIP]
> Check the `README.md` in each project for configuration and run instructions.
